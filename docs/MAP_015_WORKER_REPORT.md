## R4 final fixes — for lead audit

The lead's R3 audit independently accepted fast Truck accuracy as better than the camera method (source `34331cde`), so no new fast-versus-camera study was required. R4 closes two identified source defects:

- **LEADMAP015-05 (arrival):** the live native Train builder checks both `endTime` and `arriveTs` against capture time and excludes already arrived `train.type=1` Trucks. It keeps an individual `capturedAtMs` for accepted rows. Managed code checks arrival again when the native receipt is admitted, when rows are imported, and immediately before both Truck-only and mixed-kind block projection. Times in either Unix seconds or milliseconds normalize to one millisecond deadline, and equality means arrived. Expired records never enter new full-world Truck publication. The genuine-package auditor independently compares saved arrival deadlines to capture timestamps for every published Truck.
- **LEADMAP015-06 (lost push):** the March push's installed client handler has no rectangle ID, coordinates or echoed request identity, so the missing individual request **cannot** be safely inferred from the original overlapping sweep. The 625 fast requests now run as 25 consecutive **fenced sets of 25 requests**. A full 25/25 receive count verifies a set; a partial count leaves its entire ambiguous set unverified. After the first 625 sends, the native owner resends only rectangles **not yet verified**, one request outstanding at a time, for at most two repair passes. Genuine source still requires all 625 verified rectangles, a positive typed Truck set, matching exact owner, original camera tile and `_curViewIndex`/flag restoration; an unresolved set fails to the established camera fallback after proven cleanup. Repair receives a 210-second native bound and managed 240-second terminal/cancellation bound. The source receipt records `initialRequestsSent`, `repairRequestsSent`, `repairPasses`, `rectanglesCompleted`, `unprovenRectangles`, `responseFenceSize` and `responseAttribution` independently of raw push count. This is conservative *group* attribution for overlapping requests, not a fabricated per-push rectangle echo; spontaneous or delayed pushes are a remaining transport limitation for lead review.
