# MAP-016 owner direction and behavior differences

This ledger records changes requested in `docs/work-items/LWB317-MAP-OWNER-FIXES-016.md` relative to the accepted MAP-015 release. The recovered private original program is not claimed as the source of these policies.

| ID | Classification | Owner-facing behavior | Evidence and qualification |
| --- | --- | --- | --- |
| MAP-016-D01 | OWNER_DIRECTION | Eliminate Scheduled Plunder, auto plunder, Random delay and persisted scheduled jobs. Previously saved automatic-plunder jobs are retired on opening an existing database; no account action is attempted. | Backend/compatibility tests and actual packaged Map screenshots; archived job schema remains readable for safe migration. |
| MAP-016-D02 | OWNER_DIRECTION | Remove the Map's Add to schedule and Share to alliance features. Retired command names now return `FEATURE_REMOVED`; saved scans and passive browse/Jump are retained. | Command rejection and mounted UI checks; no live share/plunder actions are authorized. |
| MAP-016-D03 | OWNER_DIRECTION | Remove Normal/Fast selections from Manual and Auto; run the fastest qualified scanner automatically, with guarded native cleanup and source-dependent fallback. Older saved `scanMode=normal` remains loadable and normalizes to automatic fast. | Source-owned Auto/manual controlled tests and packaged UI; a fallback is still rejected when exact native restoration cannot be proven. |
| MAP-016-D04 | OWN_DESIGN | On reconnect, enabling Auto does not fire an overdue saved schedule. The first eligible run waits a full configured interval; explicit Run now is immediate. Automatic progress is labeled accordingly. | `Map016LaunchScheduleChecks`, saved legacy launch/config and actual packaged status. |
| MAP-016-D05 | OWN_DESIGN | Browse **All servers** from saved servers in one list, with source server per row, server-aware ordering, filters, exported counts and correct Jump target.
