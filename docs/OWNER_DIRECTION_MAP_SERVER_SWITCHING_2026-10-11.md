# Owner Map clarification — server switching

2026-10-11. Direct owner instruction:
"I allow to switch around other server, but not plundered, claims and, sharing.
I will do that myself."

This extends MAP-006 live scope to bounded server switching, including multi-server
passive scans and Auto target/return verification. Keep task-only configuration,
current build/server admission, exact session identity, backup/restoration and
explicit pause/stop gates. Observe the actual reached server before acquisition;
never publish another server's rows under the requested server's identity.

Live plunder, Treasure claims and sharing remain disallowed for worker execution.
Their code and controlled tests remain in scope; owner will perform those real
actions personally. Do not arm jobs that execute them as a side effect of testing
the scheduler. Paid spending, unrelated combat/updater and protected-service
access remain excluded. Read-only map-camera activity needed by authorised scans
is allowed; this instruction does not authorise march initiation or arbitrary
account-affecting actions.

This supersedes the older same-server-only / ask-before-server-switching limit
in MAP-006. It does not turn untested functions into accepted features.
