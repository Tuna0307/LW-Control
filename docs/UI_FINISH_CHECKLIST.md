## Verification discipline

Reuse accepted proofs and current adapters. Add distinguishing actual-render,
handler and deferred-state cases for changed or unreviewed branches. Commit
small coherent milestones. Do not repeatedly replay expensive unaffected suites
after they pass. Preserve all historical evidence and unrelated WIP. Browser
fixtures are explicit, preview-only and offline; native actions stay fenced.
No login/account/licensing UI, redesign, fallback, native gameplay or legacy
retirement work is included in this queue.

At final closure, report separately: source/local UI completed branches;
unresolved UI branches/assets; original visual comparison limits; native/live
limits. A deadline does not convert a pending or blocked branch to complete.
