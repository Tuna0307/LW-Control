# R8-037 — restore append_log runtime logging

**Date:** 2026-09-25
**Reference:** verified LWBridge 0.3.1
**Scope:** replace the rebuild no-op with the recovered profile-runtime log append contract.

## Authority

Primary native evidence:

- `append_log` handler function RVA `0x12FC8E`-`0x13050B`;
- profile-runtime resolver RVA `0x2AE43C`;
- 2,000-Unicode-scalar truncation helper RVA `0x393D5A`;
- line CR/LF sanitizer RVA `0x3F5C8C`;
- runtime log writer RVA `0x3CE0D2`;
- Unix-millisecond clock RVA `0x23F1C0`;
- recovered format descriptor bytes near RVA `0xD0A724`;
- retained frontend wrapper `append_log({message})` with selected `profileId` injection.
## Recovered public behavior

The retained frontend wrapper passes `{message}`. The shared invoke wrapper injects the selected `profileId` when it is absent.

Native then:

1. resolves the requested profile runtime;
2. requires `message` to deserialize as a string;
3. takes at most 2,000 Unicode scalar values;
4. replaces each CR and each LF scalar with one ASCII space;
5. writes one UTF-8 log line;
6. returns unit/null.

The exact normal-path line is:

```text
[<unix-milliseconds>] [bridge-app] <sanitized-message>\n
```
The destination is the profile runtime's:

```text
logs/xlua-bridge.log
```

R8-037 wires this to the rebuild's existing retained profile runtime directory:

```text
profiles/<profileId>/runtime/logs/xlua-bridge.log
```

No global LocalConfig log file is introduced.
## Message normalization

The 2,000 limit is based on Unicode scalar values, not UTF-8 bytes and not UTF-16 code units.

Therefore a supplementary-plane character such as an emoji counts as one element and is never split into an invalid surrogate half by truncation.

The line sanitizer processes CR and LF independently. For example, `"a\r\nb"` becomes `"a  b"` with two spaces.

An empty string is a valid native string and produces a line whose message portion is empty.
## Errors and best-effort write policy

The profile-runtime resolver provides stable native codes:

- missing, blank or non-string `profileId` -> `PROFILE_ID_REQUIRED`;
- unavailable profile runtime -> `PROFILE_RUNTIME_UNAVAILABLE`.

Malformed/missing `message` is rejected by the Tauri argument-deserialization boundary before the writer. The exact framework-generated text is not claimed by R8-037; the rebuild rejects that malformed input as `INVALID_PAYLOAD`.

Native log I/O is best effort. File/open/write/format failures are not surfaced as command failures. R8-037 mirrors that normal command behavior: valid requests still return null if the local log append cannot be completed.
## Rotation boundary

Static recovery also exposes a wider runtime log manager with `segments` and multiple managed log names.

R8-037 does not claim or invent the full rotation/retention policy. That manager is separate from the recovered `append_log` observable contract and can be recovered later if product behavior requires exact segment retention.

The implemented command therefore closes the prior no-op deviation without asserting unproven rotation limits.
