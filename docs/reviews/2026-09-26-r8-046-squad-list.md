## Request/profile admission

Native resolves `profileId` as an optional string field, trims it, and requires a non-empty value. Missing, null, non-string, or blank profile identity fails with exact:

- code: `PROFILE_ID_REQUIRED`
- message: `PROFILE_ID_REQUIRED`

A profile that does not resolve to a retained runtime fails with exact:

- code: `PROFILE_RUNTIME_UNAVAILABLE`
- message: `PROFILE_RUNTIME_UNAVAILABLE`

The retained rebuild implements those command-specific native errors instead of routing `squad_list` through its older generic `PROFILE_REQUIRED` / `PROFILE_SCOPE_MISMATCH` validation.
## Game-call contract

After profile/runtime resolution, native requires the selected game route. Missing game connectivity fails with exact `GAME_DISCONNECTED` / `game disconnected`.

Native then issues exactly one game call:

- method: `getSquads`
- args: `{}`
- result deadline: `5,000 ms` (`0x1388`)
- no host retry loop.

If no correlated result is known when that deadline expires, native returns:

- code: `LUA_CALL_TIMEOUT`
- message: `lua call result unknown after timeout: getSquads`

The apparent leading byte `0x27` before the timeout literal is the Rust format-piece length (39 decimal), not an apostrophe in the public message. The shared result-error path uses `LUA_CALL_FAILED`; with a returned error string it formats `lua call failed: <error>`.

## Success result

The `squad_list` handler does not rebuild or normalize a public squad DTO. It sends the correlated game result through the generic JSON result converter and returns that JSON value.

The retained frontend consumes `result.squads` directly. Separate native squad-processing code confirms the game payload vocabulary includes `squads`, squad `index`, `positions`, `heroes`, and hero/equipment fields including `uuid`, `name`, `position`, `equips`, and derived `squadIndex`; those fields are evidence about the game payload, not a host-side rewrite contract.

R8-046 therefore forwards the correlated `getSquads` JSON unchanged, including opaque fields not known to the host.
