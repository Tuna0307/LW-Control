# R8-099 — recover decrypted bridge module-table format and exact source assembly

**Date:** 2026-09-27
**Reference:** verified LWBridge 0.3.1
**Scope:** post-AES plaintext parser and exact Lua-source assembly; no product scanner change.

## Result

R8-098 proved that the original proxy ultimately compiles Lua text as `@bridge-scripts.dat`. R8-099 now recovers what sits immediately before that source buffer.

The AES-GCM plaintext returned by the original package decryptor is **not** one already-concatenated Lua script. It is a format-2 module table parsed by proxy helper RVA `0x125C0`.

The caller at RVA `0x1CC54` passes the decrypted plaintext to this parser. The parser sets its format output to exact integer `2`.

## Exact plaintext table

The plaintext starts with:

```text
u32_le moduleCount
```

`moduleCount` must be between 1 and 1024 inclusive.

Each module entry is exactly:

```text
u32_le nameLength
u32_le sourceLength
name[nameLength]
source[sourceLength]
```

The parser advances by exactly `8 + nameLength + sourceLength` bytes per entry.

Module names are non-empty and every byte must be one of:

```text
.0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ_abcdefghijklmnopqrstuvwxyz
```

The parser rejects malformed bounds/metadata as `invalid entry metadata` / `invalid entry`.

## Bootstrap ownership

The module name `bootstrap` is special.

A non-empty bootstrap source is required before terminal success. The parser has dedicated `duplicate bootstrap` and `bootstrap missing` failures. Terminal success also requires exact consumption of the decrypted plaintext; otherwise it reports `trailing package data`.

The bootstrap source is not wrapped in `package.preload`. It is appended raw at the very end of the synthesized script.

## Exact generated Lua source

The parser begins the output with exactly:

```lua
local __bridge_preload = package.preload
```

including the trailing newline.

For every non-bootstrap module named `<name>` with source `<source>`, it appends exactly:

```lua
package.loaded["<name>"] = nil
__bridge_preload["<name>"] = function(...)
<source>
end
```

The exact static byte fragments are:

- `local __bridge_preload = package.preload\n`
- `package.loaded["`
- `"] = nil\n`
- `__bridge_preload["`
- `"] = function(...)\n`
- `\nend\n`

After all non-bootstrap wrappers, the raw bootstrap module source is appended.

The assembled source is then copied into the output string. The successful package/auth refresh path later replaces the proxy-owned bridge source global recovered in R8-098:

- secure proxy: RVA `0x8F170`;
- plain proxy: RVA `0x90170`.

## Important consequence

The remaining protected script package is now narrowed to two layers with exact public-side structure:

1. LWBP2 AES-GCM decrypt -> **format-2 module table**;
2. module-table parser -> exact concatenated Lua source -> R8-098 compiler -> bytecode -> game xLua state.

Therefore once authentic AES plaintext becomes available, no additional reverse engineering is needed to identify module boundaries or reconstruct the final source. The module table can be split deterministically and searched directly for `XluaBridgeMapScanTick`.
