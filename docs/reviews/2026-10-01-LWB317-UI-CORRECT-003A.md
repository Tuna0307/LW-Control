# LWB317-UI-CORRECT-003A — weekly quality settings

**Date:** 2026-10-01

**State:** AWAITING_REVIEW

**Branch:** research/offline-controller

## Result and scope

This focused continuation verifies and corrects only the seven-day quality
settings in Trucks and Secret Task. Trade, Dispatch Assist, AFK, Map and the
remaining CORRECT-003 backlog were not continued.

The original weekly defaults are:

- Trucks: `ssr, ur, ssr, ssr, ssr, ur, ssr`.
- Secret Task: `none, ur, none, none, none, ur, none`.

The source creates seven UTC weekday labels from 2024-01-01 through 2024-01-07,
which yields Monday through Sunday. Each day has the three values `none`,
`ssr` and `ur`, rendered as Do not refresh, SSR or above, and UR.

The recovered handler copies the current seven-value array, changes only the
selected index, patches `weeklyQualities` and flushes the task draft. Browser
interaction confirmed that changing Trucks Monday did not change the other six
Truck days or any Secret Task day. The edited draft also survived settings
collapse, category switching, and navigation away from/back to Automation.

## Save and restriction behavior

Actual browser edits exercised both failure branches. A failed Trucks Monday
edit retained the edited draft and displayed Retry plus Discard unsaved
changes. Retry confirmed that edited weekly array. A separate Secret Task
Monday failure followed by Discard restored its confirmed default array.

The source disable predicate for these weekly selects is `!online || taskBusy`
plus the card's own runtime-running argument. The original AutomationCard
fieldset uses offline/configDisabled with the same task predicate. Config-draft
saving is tracked for status/error handling, but it does not disable the weekly
select itself; only Retry/Discard are save-locked while saving.

The clone had an extra `config.saving` selector lock. That weekly-only parity
defect was removed from `WeeklyQualityPreview` and both call sites. A deferred
write through the actual `createConfigDraft` store confirms that a second
weekly edit can be made while the first write is in flight, then queues and
becomes the confirmed value after both acknowledgements.

The preview validator still rejects arrays that are not exactly seven values
from `none/ssr/ur`. This is a preview boundary check. The original frontend
normalizer does not contain an equivalent explicit weekly-array validator; its
fixed seven selectors constrain UI-authored values.

Browser checks also confirmed all seven weekly selectors are disabled for both
cards in the runtime-running fixture and in the offline preview. The two
failure fixtures retain the original automation-off defaults.
