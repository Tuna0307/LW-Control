## Reachability and fixture classification

The recovered renderer fields and predicates are source-executed. Browser states under `automation-*` are explicitly disclosed deterministic preview fixtures. They prove frontend presentation and local state transitions only; they do not prove native producer behavior, protected bridge availability, or gameplay success.

The complete untouched recovered desktop frontend is blocked from ordinary-browser boot by its protected bridge. This is a genuine original-runtime blocker, not converted into a fabricated match. Actual recovered functions and the recovered CSS remain the original-side oracle for Unit C.
