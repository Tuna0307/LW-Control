Game Hotkeys

Fixed shortcuts that respond while the Last War game window is active.
Game connected
Q / W / E / R

Attack target

Q/W/E/R each send one march at whatever is under the cursor: enemy city, ally city reinforcement, monster, resource node, or city ruin. World bosses and rally monsters are skipped. A/S/D/F recalls.

Items are spent first, cheapest tier first. Diamond purchases pick the lowest-priced tier and spend real diamonds.
Enabled
A / S / D / F

Recall squad

Recall squads 1–4 to the Headquarters.

Enabled
Space

Shield countdown

Hold Space to display remaining Shield time above protected cities.

Enabled
F6 / F7 / F8

Use Shield

F6 uses an 8-hour Shield, F7 a 12-hour Shield, and F8 a 24-hour Shield.

Disabled
This shortcut consumes the matching Shield item immediately.
Alt + 1～4

Equipment preset

Apply equipment presets 1–4 to all configured squads.

Enabled
F9

Random relocation

Press F9 to use a Random Relocator.

Disabled
Relocation may consume an item. This shortcut is disabled by default.
F10

Alliance relocation

Press F10 to relocate to the Alliance rally point.

Disabled
Relocation may consume an item. This shortcut is disabled by default.
