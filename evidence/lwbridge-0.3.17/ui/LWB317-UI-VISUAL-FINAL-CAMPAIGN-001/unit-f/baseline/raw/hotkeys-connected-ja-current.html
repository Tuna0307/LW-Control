ゲームショートカット

Last Warのゲームウィンドウがアクティブなときに使える固定ショートカットです。
ゲーム接続済み
Q / W / E / R

目標を攻撃

Q/W/E/Rを1回押すごとにカーソル下の対象へ1回出兵します。敵都市への攻撃、味方都市への増援、通常モンスター、資源採集、都市遺跡に対応。ワールドボスと集結モンスターは除外します。A/S/D/Fで帰還。

所持アイテムを低い段階から優先使用します。ダイヤ購入は最安の段階を選び、実際にダイヤを消費します。
有効
A / S / D / F

部隊を帰還

第1～4部隊を基地へ帰還させます。

有効
Space

シールドの残り時間

スペースキーを押している間、保護された都市の上にシールドの残り時間を表示します。

有効
F6 / F7 / F8

シールドを使用

F6で8時間、F7で12時間、F8で24時間のシールドを使用します。

無効
キーを押すと対応する時間のシールドアイテムを即座に消費します。
Alt + 1～4

装備プリセット

設定済みの部隊に装備プリセット1～4を適用します。

有効
F9

ランダム移転

F9でランダム移転アイテムを使用します。

無効
移転はアイテムを消費する場合があります。このショートカットは初期状態では無効です。
F10

同盟移転

F10で同盟の集合地点へ移転します。

無効
移転はアイテムを消費する場合があります。このショートカットは初期状態では無効です。
