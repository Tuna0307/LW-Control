Горячие клавиши игры

Фиксированные сочетания клавиш, работающие только в активном окне Last War.
Игра подключена
Q / W / E / R

Атаковать цель

Каждое нажатие Q/W/E/R отправляет один марш к цели под курсором: вражескому городу, союзному городу для подкрепления, обычному монстру, точке ресурсов или руинам города. Мировые боссы и монстры для сбора пропускаются. A/S/D/F — отзыв.

Сначала расходуются предметы из инвентаря, начиная с самого низкого уровня. За алмазы покупается самый дешёвый вариант; алмазы действительно списываются.
Включено
A / S / D / F

Отозвать отряд

Вернуть отряды 1–4 на базу.

Включено
Space

Таймер щита

Удерживайте пробел, чтобы показать оставшееся время щита над защищёнными городами.

Включено
F6 / F7 / F8

Использовать щит

F6 использует щит на 8 часов, F7 — на 12 часов, F8 — на 24 часа.

Отключено
Нажатие сразу расходует предмет щита соответствующей длительности.
Alt + 1～4

Набор снаряжения

Применить наборы снаряжения 1–4 к настроенным отрядам.

Включено
F9

Случайная телепортация

Нажмите F9, чтобы использовать случайный телепорт.

Отключено
Телепортация может расходовать предмет. По умолчанию эта горячая клавиша отключена.
F10

Телепортация к альянсу

Нажмите F10 для телепортации к точке сбора альянса.

Отключено
Телепортация может расходовать предмет. По умолчанию эта горячая клавиша отключена.
