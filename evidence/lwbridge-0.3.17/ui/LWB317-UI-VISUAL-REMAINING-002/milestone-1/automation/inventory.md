recovered renderer/helper functions and recovered CSS are therefore the original-side
oracle. Deterministic `automation-*` preview producers prove frontend presentation and
local transitions only. Native automation execution/gameplay success is not claimed;
missing providers stay fenced. No synthetic “successful run” can close a native
producer dependency.
