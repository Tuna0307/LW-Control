# Milestone 4 whole-shell source-render proof

This packet closes the Milestone 4 whole-shell composition evidence gap. `render-shell-pairs.mjs` parses the pinned recovered `index-BVfnK1wp.js` asset and executes the actual recovered `Gi`, `Fn`, `si`, `Yr`, `Qr`, `ti`, `In`, `Ji`, `qi`, and `Oe` functions plus their recovered shell helpers. The current side executes the canonical current App return expression and current `ShellPresentation`, `ProfileSidebar`, `ProfileSwitchState`, `AppExitDialog`, `NavIcon`, and `RetainedPages` implementations. It does not hand-author either shell DOM.

`source-locators.json` pins the recovered source asset and source-function byte ranges/hashes. `renderer-inputs.json` records all 16 branch cases and the controlled provider substitutions. The required matrix covers single-profile EN/light and JA/dark, header update/status/theme/language, compact/expanded/error-forced-open profiles, note dialog, drag/over state, uncached loading and cached return, four ordered save errors, Cross-server closed/open, exit idle/busy, and a 720px JA/dark multi-profile composition. The cached-return browser state also records selected, hover, and focus presentation. Unavailable updater/status/profile native providers stay fenced.

The recovered and current route-page bodies use the same inert panel sentinel because page-body proof belongs to the page milestones; the shell still executes its real route/Suspense/profile-view ancestry. Recovered auth/account/upgrade UI and current provider-disabled controls remain raw visible differences according to project scope. Original/current image URL imports use the same inert data URL. React effects are deliberately inert in source rendering, and browser capture opens rendered dialogs with `showModal()` so their recovered modal presentation is measured without subscribing to native events.

`capture-shell-pairs.mjs` loads each source-rendered side in a fresh headless browser context with independent CSS: recovered `index-rIL9Fpht.css` for original and current `reference.css + styles.css` for current. `browser/pairs.json` records PNG/HTML/measurement hashes and console issues. Per-side measurement JSON contains raw DOM, geometry, selected computed styles, pseudo styles, text runs, focus, shell ancestry, and exit sibling placement. `compare-shell-pairs.py` records unmasked pixel and measurement differences in `browser/comparison-results.json`; no mask converts scope/provider differences into a parity claim.

`mutation-check.mjs` proves the packet detects two meaningful composition defects: removing `aside.profile-sidebar`, and moving the exit dialog inside `main.app-shell`. `validate-read-only.mjs` recomputes dependency and artifact hashes, reruns source rendering in `--verify` mode, recomputes the saved pixel/measurement comparison in `--verify` mode, reruns the mutation detector in `--verify` mode, and checks the required branch/ancestry/fence assertions without writing or repinning evidence.
