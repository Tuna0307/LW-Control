# Tooling note

Most existing scripts in this directory were created during LWBridge 0.3.1/current-client research.

They are valuable, but their constants, offsets, schemas and assumptions must not be treated as 0.3.17 facts without revalidation.

## New 0.3.17 tooling

Put new version-specific helper scripts under:

`tools/lwbridge317/`

Prefer small focused tools with a matching `LWB317-*` finding rather than adding more unclassified scripts to the top-level tools directory.
