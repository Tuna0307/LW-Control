# MAP-019 private Truck send-rate diagnostic

Build this distinct host without rebuilding the active native host output:

```powershell
dotnet build tools/map_019_review/mobile_native/MobileReview.csproj -c Release -p:SkipCanonicalProductionUiBuild=true
```

The primary's `run_owned.py mobile-review` selects this host and retains the existing exact-owned game
admission/start, lease renewal, terminal stop and installed-script restoration machinery. Do not invoke it
against an owner session. The host itself takes only `owner.json mobile-review` and never launches the game.

The six same-session observations are native20, camera, camera, native20, native15, native15. Native rounds
call the current private `ProbeFastTruckAsync` with an opt-in rate, preserving its exact ownership/freshness,
bounded cancel and625-rectangle fence/repair gates. Production remains20. Camera controls use the production
scanner with `ForceLegacyFullWorldLens`, isolated diagnostic SQLite, exact-run native10000-AOI metrics and
independent before/after camera geometry. They invoke scan commands only; no action command is called.

The changed hypothesis relative to pre-R4 experiments is that lower initial send rate may reduce current
selective repair overhead. Rate15 is not presumed faster or complete. The raw owner-bound native receipts,
camera databases, normalized production rows, camera checkpoints, timing/repair summary and all-pairs
identity/field comparison matrix remain private in the owned attempt directory. Source rows are normalized
through production `PrepareTrainRecords`, the same fixed receipt-time arrival admission and final metadata
enrichment. Native-only timings exclude normalization and camera checkpoints and are not publication timings.

`mobile-field-drift-comparisons.json` records common identities, missing/added identities, missing objects
already expired at later admission, and per-field changes. Moving coordinates are deliberately not stable
field errors. Arrival/loot and newly launched Trucks can change naturally; this finite matrix emits no
automatic accuracy or speed acceptance. Qualify against the same-method controls before recommending a rate.
An exception stops further rounds and the external helper must complete its exact native stop/restoration.
